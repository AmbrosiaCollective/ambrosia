# Ambrosia graphics

- `wordmark.svg` / `wordmark.png`: flowing text-only project logo, transparent.
- `logo.svg` / `logo.png`: single-character A emblem, transparent.
- `banner.png`: transparent text-only wordmark in a wide layout.
- `favicon.ico`: the character emblem at common icon sizes.

SVG files are self-contained layouts with embedded PNG artwork; the lettering is
raster, not traced vector paths. The agreed blue/violet/pink/coral gradient and
palm details are inside the lettering. No scenic background is included.
